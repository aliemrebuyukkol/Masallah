# Contemporary Developer Tool Product Launch Page

- **Category:** Design
- **Source:** [Recent Design](https://recent.design)
- **Target Model:** Claude 3.7 Sonnet / Gemini 2.5 Pro
- **License:** MIT (Masallah Abstracted Prompt)
- **Tags:** Design, Website, Landing Page, UI, Prompt

## Description

Blueprints a high-craft product launch page featuring interactive command-line preview, real-time telemetry bento cards, and zero-clutter visual hierarchy.

## Original Prompt

```text
Build a clean landing page for a new developer tool launch with dark mode and feature cards.
```

## Masallah Optimized Prompt

```text
Design a contemporary product launch landing page inspired by Recent Design's modern launch showcases:
- Hero Stage: Centered badge ("v2.4 Live"), 64px tight grotesk headline, dual CTAs (Primary high-contrast + interactive CLI copy pill `npx create-workspace@latest`), and a 16:10 interactive browser/terminal split frame below.
- Bento Telemetry Grid: 3-column asymmetric bento layout where each card demonstrates a real interactive state (live latency graph, keyboard-navigable command list, diff viewer) rather than static decorative illustrations.
- Visual Restraint: Monochrome slate surface (#090A0F) with 1px inner border highlights (inset 0 1px 0 rgba(255,255,255,0.1)) and semantic status indicators (#10B981 emerald for live metrics).
```

## Example Input

Tool: "PulseTrace" — zero-overhead edge observability & distributed request replay CLI.

## Example Output

Responsive React landing page with interactive trace waterfall preview, copyable CLI installer with toast feedback, and 3-tier transparent pricing table.
