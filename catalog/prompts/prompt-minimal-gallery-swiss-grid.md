# Swiss Architectural Grid & Bichromatic Editorial Layout

- **Category:** Design
- **Source:** [Minimal Gallery](https://minimal.gallery)
- **Target Model:** Claude 3.7 Sonnet / Gemini 2.5 Pro
- **License:** MIT (Masallah Abstracted Prompt)
- **Tags:** Design, Minimalism, Website, UI, Prompt

## Description

Creates an ultra-restraint Swiss modernist web layout relying solely on mathematical grid proportions, typographic scale, and exposed 1px rules.

## Original Prompt

```text
Design a minimalist website using Swiss grid layout and clean typography.
```

## Masallah Optimized Prompt

```text
Build a Swiss-grid minimalist web interface inspired by Minimal Gallery editorial principles:
- Strictly prohibit decorative gradients, drop shadows, blurred glassmorphism, or stock icons.
- Construct the layout using an exposed 8-column CSS Grid where every cell is separated by a 1px solid rule.
- Use a strict bichromatic palette: Warm Paper (#F6F5F0) and Carbon Ink (#121212) in light mode, inverting to #0C0C0D and #ECEBE6 in dark mode.
- Establish hierarchy purely through typographic scale (64px / 28px / 16px / 12px uppercase tracked labels) and 50%+ negative whitespace.
- Include an interactive tabular index view that toggles seamlessly between "Grid View" and "Specification Index Table".
```

## Example Input

Archive: "Typographica Monograph" — catalog of 40 open-source variable typefaces.

## Example Output

Bichromatic Swiss grid interface with live variable font weight/width axes sliders and tabular specification index.
