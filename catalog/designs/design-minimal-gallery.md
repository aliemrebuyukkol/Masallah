# Swiss Neo-Brutalist & Editorial Minimalist System

- **Source:** [Minimal Gallery](https://minimal.gallery)
- **Category:** Design
- **Technologies:** CSS Grid, Editorial Typography, Semantic HTML

## Visual Analysis

- **Layout:** Exposed 4-column and 8-column Swiss architectural grid with strict baseline alignment and 45%+ negative whitespace.
- **Typography:** Neo-grotesk sans (Helvetica Now / Inter Tight) paired with raw tabular numerals; zero decorative shadows.
- **Color System:** Strict bichromatic palette: Warm Paper (#F7F6F2) and Carbon Ink (#111111) or inverted Obsidian (#0B0B0C) and Chalk (#EDEDEA).
- **Spacing:** Mathematical 8pt/16pt/32pt/64pt modular scale with exposed 1px solid hairline borders.
- **Motion:** Micro-opacity shifts (1 → 0.65) and crisp 150ms border color transitions.
- **Components:** Swiss Index Table, Editorial Spec Sheet, Monochrome Aspect-Ratio Frame
